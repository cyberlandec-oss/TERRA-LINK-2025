Hay 5 negocios diferentes

Tipo de negocio	Qué vende realmente

First-mile / trazabilidad	Datos confiables desde productor/parcela

Nuestra plataforma debe combinar estos cinco, pero sin intentar ser una copia literal de todos ellos.
